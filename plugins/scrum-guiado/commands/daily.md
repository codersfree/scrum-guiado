# Daily

Explica, la primera vez, qué es una daily (revisión corta diaria: ayer, hoy, bloqueos). Lee las tareas `en-progreso` y `pausada` en `docs/scrum/items/`, el sprint actual (`docs/scrum/configuracion.md`) y `git log --since=yesterday --oneline`.

Presenta:
```
Ayer: ... (de las bitácoras y commits)
Hoy: ... (próximo paso de cada tarea)
Bloqueos: ...
Sprint: <objetivo> — <hechas>/<total> historias
```
Pregunta si algo cambió y, con su respuesta, actualiza las bitácoras. Si hay un bloqueo externo, regístralo en `docs/scrum/impedimentos.md` (IMP-##).
